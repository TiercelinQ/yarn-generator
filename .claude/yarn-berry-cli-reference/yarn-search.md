# yarn search

Ouvre l'interface de recherche.

Source : aide `yarn search --help` (Yarn 4.18.1), https://yarnpkg.com/cli/search

## Usage

```
yarn search
```

## Options

Aucune.

## Détails

La commande ouvre une interface terminal plein écran pour rechercher et installer des paquets du registre npm.

## Exemples

Ouvrir la fenêtre de recherche :

```
yarn search
```
